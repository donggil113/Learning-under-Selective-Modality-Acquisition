### 6.2 고정한 적격 모집단과 예측 시점 (PhysioNet 2012)

* **label**: 병원 내 사망(유병률 14.2%; 세트 a/b/c 13.9/14.2/14.6%).

### 7.3 단순 표본 선택·class balance로 설명되는가? (수행 8, 둘째 질문)

1. **class balance.**
   * 추정 유병률로 조정하는 EM(Saerens) 방식은 **파국적으로 실패**한다. 추정 유병률은 cc 4.2 ± 1.3%, 참값은 14.6%다. τ는 cc Brier 0.244, log loss 0.049다. label-shift 가정(P(X∣Y) 불변)이 완전사례 선택과 맞지 않기 때문이다.
   * plug-in 유병률은 τ를 소폭 올린다(0.649 → 0.684).
   * 참 유병률을 알려줘도 τ는 오르지 않지만(0.608), dropout p=0.5의 유의 반전 13개 중 **6개**(log loss 15개 중 8개)를 복구한다.
2. **표본 선택(기저 공변량 IW).** 유의 반전을 run당 0.25개로 줄인다(3/12 run). 다만 τ는 0.673으로 비율 dropout과 같은 수준이고, dropout 반전 13개 중 복구한 것은 0개다. 줄어든 것은 반전이라기보다 결정 수(40.2%)다.
3. **진실 세트 내부 사다리**(V = T의 완전사례, U = T; V–T 표본 잡음 제거). cc Brier τ는 다음과 같다: masking 없음 0.679 → dropout p=0.5 0.691 → 패턴 빈도 0.724 → +plug-in 0.740 / +참 유병률 0.666 → 표본 선택 IW 0.730 → 패턴 IW 0.662 → DR 0.579. **패턴 빈도 맞춤과 plug-in 유병률까지가 설명 가능한 몫이고, 그 이상의 공변량 보정은 순위를 개선하지 않는다.**
4. **교차 ICU(추가 모집단 이동).** 여기서는 **결과모형 기반 보정이 도움이 된다.** plug-in(Γ=1) τ 0.632로 최고이고, DR은 dropout 반전 20개 중 **17개**를 복구한다. class balance는 0개를 복구한다. 이동의 대부분이 관측 공변량으로 설명되는 모집단 이동이기 때문이다.

**요약:** 완전사례 설계의 반전은 절반가량이 class balance로, 교차 ICU 설계의 반전은 대부분이 관측 공변량 보정으로 설명된다. **남는 부분은 label 의존 기록이다(§7.4).**

* 기록된 특징을 조건으로 해도 **Y ⟂ M ∣ X_o(m)은 기각된다.** 기록이 적을수록 같은 x_o에서 사망 위험이 낮고, panel당 대략 λ ≈ 1.2–1.3이다. 이것이 "label 의존 기록"이다.
* 반대 방향 패턴(1101: 다른 panel은 있는데 젖산만 없음)이 있으므로 **한쪽 방향 가정("결측 ⇒ 덜 위험")은 이 자료에서 틀린다.**
* 이것은 **M**에 대한 사실이다. 임상의가 덜 아픈 환자에게 검사를 덜 **시행**했다(A)는 해석은 §6.1에 따라 BLOCKED_REALDATA다.
* 쌍별 위험 차에서 이 항의 크기(cc Brier): 불완전 단위의 label 항이 진실-유의 쌍의 **25.3%**에서 진실 차보다 크다. 즉 무시하면 부호가 바뀔 수 있다. 음성 대조인 완전 단위에서는 0.9%다. 쌍의 65.8%에서 CI가 0을 배제하고, 대조군은 38.9%다(대조군에서도 0이 아닌 것은 결과모형 오차를 뜻한다). 교차 ICU에서는 각각 4.5% 대 0.2%다.
* Γ 보정 가능성: 라벨이 있는 **개발 세트** D에서 추정한 패턴별 log-OR과 T에서의 값은 cc에서 r = 0.64(평균 절대차 0.29)이고, T 패턴의 95%가 D의 최대 Γ 안에 있다. 교차 ICU에서는 r = 0.41, 88%다.

### 7.5 후보 방법(acquisition-aware selection)의 성능 (수행 5)

bootstrap 95% CI를 식별 구간에 씌운 결정 규칙이다. **CI_lo(L*) > 0 또는 CI_hi(U*) < 0일 때만 결정**한다. 정보는 {V, U}로 다른 규칙과 같다.

| 규칙 (cc, Brier) | 결정 비율 | 정답률 | CI가 참 Δ 포함 |
|---|---|---|---|
| dropout p=0.5 + bootstrap | 49.8% | 95.4% | 70.9% |
| 표본 선택 IW + bootstrap | 40.2% | 95.3% | 86.2% |
| AA Γ=1 (= DR + bootstrap) | 35.8% | 94.3% | 84.0% |
| AA 한쪽, panel λ=1.2 | 23.7% | 96.5% | 95.9% |
| AA 양쪽, panel λ=1.2 | 12.9% | 100% | 98.7% |
| AA 양쪽, 스칼라 Γ=1.5 | 10.6% | 100% | 99.4% |
| AA 양쪽, 스칼라 Γ=2 | 2.7% | 100% | 100% |

다른 설정에서의 결정 비율 / 정답률:

| 설정 | dropout p=0.5 | AA 한쪽, λ=1.2 | AA 양쪽, λ=1.2 |
|---|---|---|---|
| cc, log loss | 64.3% / 97.2% | 33.3% / 99.8% | 21.0% / 99.9% |
| 교차 ICU, Brier | 34.0% / 88.6% | 18.1% / 99.0% | 8.6% / 100% |

**해석:**

* 자료가 시사하는 λ ≈ 1.2에서 AA는 **틀린 확신을 거의 없앤다**(정답률 96.5–100%, CI 포함률 96–99%).
* 대가로 결정하는 쌍이 dropout의 약 1/4–1/2로 줄어든다.
* **정답으로 결정한 쌍의 비율**로 보면 dropout(0.498×0.954 ≈ 0.48)이 AA 한쪽 λ=1.2(0.237×0.965 ≈ 0.23)를 이긴다.
* 즉 AA는 기준선을 **지배하지 못한다.** 오류율과 결정률 사이의 다른 교환점일 뿐이다. 교차 ICU처럼 dropout의 오류가 커지는 경우(정답률 88.6%)에만 이 교환이 분명히 유리하다.

### 7.6 반합성 검증 (기전을 알 때)

실제 특징과 label은 그대로 두고 mask 기전만 **알고 있는** 설정이다(`src/n1/run_semisynth.py`).

* 자료: 완전 기록 stay 2,677개(모든 panel 값이 실제로 존재)만 사용한다.
* mask 생성: logit P(M_k=1∣x0,y) = α_k + β·s(x0) + δ·y. panel마다 독립이며, 가용률은 0.85/0.80/0.70/0.60이다. s(x0)는 나머지 9,323 stay로 적합한 기저 중증도 점수다.
* 참 민감도: 이 기전에서 패턴 m(결측 panel r개)의 odds ratio는 정확히 exp(−δ·r)이다. 따라서 참 panel당 λ* = e^δ, 방향은 "down"이다.
* 규모: 기전 5종 × 반복 8회. 진실은 T 단위에 대해 알려진 mask 법칙으로 계산한 **기댓값** 위험이다.

**Kendall τ (Brier)**

| 평가 규칙 | MCAR | MAR (β=0.75) | δ=0.25 | δ=0.5 | δ=1.0 |
|---|---|---|---|---|---|
| dropout p=0.5 | 0.720 ± 0.053 | 0.665 ± 0.061 | 0.475 ± 0.217 | 0.275 ± 0.120 | −0.027 ± 0.090 |
| target 패턴 빈도 | 0.723 ± 0.071 | 0.634 ± 0.095 | 0.527 ± 0.187 | 0.411 ± 0.111 | 0.008 ± 0.108 |
| + class balance (참 유병률) | 0.747 ± 0.068 | 0.412 ± 0.202 | 0.530 ± 0.172 | 0.748 ± 0.043 | 0.677 ± 0.108 |
| + class balance (plug-in) | 0.725 ± 0.068 | 0.462 ± 0.182 | 0.572 ± 0.147 | 0.747 ± 0.051 | 0.317 ± 0.183 |
| 표본 선택 IW | 0.712 ± 0.080 | 0.595 ± 0.103 | 0.571 ± 0.168 | 0.677 ± 0.056 | 0.086 ± 0.123 |
| 패턴별 IW (Γ=1) | 0.677 ± 0.109 | 0.607 ± 0.130 | 0.602 ± 0.157 | 0.625 ± 0.060 | 0.081 ± 0.125 |
| DR (Γ=1) | 0.630 ± 0.102 | 0.482 ± 0.184 | 0.553 ± 0.170 | 0.634 ± 0.099 | 0.090 ± 0.147 |

쌍별 위험 차의 평균 절대 오차(×10⁻³, Brier): MAR에서 패턴별 IW 7.9, 표본 선택 IW 8.0, dropout 9.5다. δ=1.0에서는 dropout 55.4, 패턴 빈도 39.2, DR 27.2, 참 유병률 class balance 12.0이다.

**bootstrap CI를 씌운 결정 (Brier). 행마다 결정 비율 / 결정 중 정답률 / CI의 참 Δ 포함률**

| 규칙 | MCAR (λ*=1) | MAR (λ*=1) | δ=0.25 (λ*=1.28) | δ=0.5 (λ*=1.65) | δ=1.0 (λ*=2.72) |
|---|---|---|---|---|---|
| dropout p=0.5 | 50% / 97.7% / 86% | 37% / 94.6% / 84% | 47% / 84.5% / 71% | 55% / **67.9%** / 59% | 61% / **37.6%** / 36% |
| target 패턴 빈도 | 45% / 98.3% / 91% | 35% / 97.0% / 86% | 41% / 90.6% / 80% | 43% / 82.3% / 68% | 53% / 37.7% / 38% |
| AA 한쪽, λ = λ* | 36% / 95.2% / 86% | 23% / 97.8% / 91% | 20% / 96.3% / 94% | 15% / **99.5%** / 98% | 1.3% / 92.9% / 94% |
| AA 양쪽, λ = λ* | 35% / 95.1% / 88% | 24% / 96.9% / 88% | 11% / 96.9% / 97% | 1.4% / 93.3% / 99% | 0.1% / 100% / 95% |

**해석:**

1. **이론이 예측한 대로 동작한다.**
   * MCAR/MAR에서는 모든 규칙이 비슷하고, MAR에서는 공변량 IW의 쌍별 오차가 가장 작다(L2/L3).
   * label 의존이 커질수록 인공 dropout은 **확신을 가지고 틀린다**. δ=0.5에서 결정의 32%, δ=1.0에서 62%가 틀리다.
   * AA는 참 λ에서 CI 포함률 94–99%를 유지한다(L4).
2. **대가.** 참 λ에서 AA는 강한 label 의존일수록 거의 아무것도 결정하지 못한다(δ=1.0에서 0.1–1.3%). Γ=1(λ=1)에서는 추정 오차 때문에 CI 포함률이 86–91%로 명목값보다 낮다.
3. **실제 자료의 위치.** 실제 자료의 panel당 λ ≈ 1.2–1.3(§7.4)은 δ≈0.25 설정에 가깝다. 실제 자료에서 dropout의 결정 정답률(95.4%)은 반합성 δ=0.25(84.5%)보다 높다. 실제 label 의존은 방향이 섞여 있고(1101 패턴) 패턴마다 크기가 달라서, 한 방향으로 누적되는 반합성 기전보다 순위에 덜 해롭다고 볼 수 있다.
4. **참 유병률 class balance가 강한 label 의존에서 가장 견고하다**(δ=1.0에서 τ 0.68). 완전사례 선택으로 생긴 유병률 이동이 label 의존 기록의 1차 효과이기 때문이다. 다만 유병률을 모르면(plug-in 0.32, EM은 실제 자료에서 붕괴) 이 이점은 사라진다.

## 8. 판정

사전에 고정한 기준(`docs/DECISION_CRITERIA.md`)에 따른 판정:

| 기준 | 결과 | 근거 |
|---|---|---|
| (a) 방법의 새로움 ≥ moderate | **불충족** | 위험 차에 대한 결합 민감도 구간은 Guerdan et al. (ICML 2024), tilt 민감도는 Steingrimsson et al. (Biometrics 2024), Γ=1 추정은 표준 IW/DR(Zhou Prop. 1, ICYM2I, Ulichney & Coston)이다. 반박 에이전트도 C3을 marginal로 판정했다 |
| (b) 대부분의 run에서 설명되지 않는 유의 반전 | **부분** | cc: 반전 run당 약 1쌍(8/12 run), 그중 약 절반이 class balance로 복구됨. icu: 20쌍 중 17쌍이 DR로 복구됨. label 의존 기록은 실재하고 크다(§7.4) |
| (c) 같은 정보에서 기준선보다 더 많은 쌍을 정답으로 결정 | **불충족** | §7.5 |

### 최종 판정: **NO_GO** (방법) · **BLOCKED_REALDATA** (획득 의미 주장)

* **NO_GO.**
  * "acquisition-aware model selection"은 기존 연구와 실질적 차이가 없다. mask 패턴별 tilt를 두 모델 위험 차에 적용한 것이며, 실제 자료에서 기준선을 이기지도 못한다.
  * 사용자 지시에 따라 **새 loss나 새 추정량으로 문제를 덮지 않는다.**
* **BLOCKED_REALDATA.**
  * PhysioNet 2012와 UCI Heart는 "기록 없음 = 검사 미시행"을 확인할 수 없다.
  * 획득 의미를 담은 자료(MIMIC-IV 전체와 CXR/ECG/Note, eICU 전체)는 credentialing이 필요해 이 프로젝트에서 접근할 수 없다.
  * 따라서 "선택적 **획득**"(임상의 결정) 수준의 주장은 실제 자료로 검증되지 않았다. 이 보고서의 실제 자료 결론은 모두 **기록 가용성 M**에 대한 것이다.
* **남는 것(C4, moderate).** 고정된 적격 모집단과 cutoff에서 같은 25개 모델로 수행한 통제된 인공-대-자연 순위 비교다. 결론:
  1. 완전사례 코호트에서의 인공 dropout 평가는 자연 결측 순위를 **굵게는 맞히고**(τ 0.63–0.77), 유의한 반전은 드물다.
  2. 반전은 정보성 결측을 이용하는 mask-aware 모델에 몰린다.
  3. class balance와 관측 공변량 보정이 반전의 대부분을 설명한다.
  4. 남는 label 의존 기록(OR ≈ 0.46)은 Γ=1 보정 추정량을 오히려 불안정하게 만든다.

  이것은 분석 기여이며 방법 기여가 아니다. 또한 획득(A) 해석 없이 M 수준에서만 말할 수 있다.

### 다음 단계로 GO가 되려면 필요한 것

1. 주문(order) 또는 채취 시각이 있는 자료(MIMIC-IV credentialed + POE/labevents)에서 A와 M을 분리해 같은 분석을 반복하는 것. 현재 BLOCKED다.
2. 방법 쪽에서는 Guerdan et al. 2024를 넘어서는 것, 예를 들어 S와 M에 별도 민감도 파라미터를 두고 두 파라미터에 대한 순위의 **결합** 붕괴 곡선을 식별 가능한 제약(개발 세트 Γ 보정, 유병률 등식)과 함께 정식화하는 것. 이것 없이는 NO_GO가 유지된다.

## 9. 한계

* 모델 25개는 표 형식 panel이다. 영상·파형 modality는 다루지 않았다.
* V(889)가 작아 평가 규칙 사이 차이의 많은 부분이 표본 잡음 안에 있다(τ의 sd 0.06–0.13).
* 진실 T 자체에도 표본 잡음이 있어, 상위 모델들의 위험 차는 0.001 수준이다. 그래서 유의성 기반 지표를 함께 보고했다.
* bootstrap은 결과모형과 가중치 모형을 고정하고 단위만 재표집한다(모형 재적합 불확실성 제외).
* AA의 λ는 격자로 보고했다. 배포 label 없이 λ를 고르는 규칙은 개발 세트 보정(§7.4, r = 0.64)에 의존하며 검증이 불완전하다.
* PhysioNet 2012의 기록은 MIMIC-II 기반의 과거 자료다. 현재 임상 관행으로 일반화하는 것은 별도 문제다.
